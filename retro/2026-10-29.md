### 2. Builder charter: push alone, keep the body in a file, merge instead of rebase

Prevents: 11 `git push` refusals, the footer dropped on #2 to #5, the bulleted `No test:` line,
and two briefs that asked for a force push. Two builder reports proposed the same.

Replace `builder.md` "Push the branch, then open it as a draft PR so CI runs (`gh pr create
--draft`; ...)" with:

"Push the branch in its own one-line Bash call, then open it as a draft PR so CI runs (`gh pr
create --draft --body-file <file>`; ...). Keep the PR body in a file written with the Write tool,
and pass the whole file on every edit: `No test: <reason>` at the start of a line, never bulleted,
and the WUWEI footer as the last line. A branch behind its base takes a merge of origin/main,
never a rebase."

The rest of the paragraph stays. The charter grows by about one line.
