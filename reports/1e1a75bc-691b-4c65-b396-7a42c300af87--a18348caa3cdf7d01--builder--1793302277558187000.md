**The race.** A child spawned a moment ago can still show its parent's command line to `ps`. `is_relay` then misses `relay.py` and `headless` reads the wrong arguments. A slow `ps` under load also pushed `test_listen_in_a_headless_run_returns_at_once` past its 1 s bound.

**The fix.** I added `Base.visible` in `tests/test_adapters.py`. It polls `ps` until the stand-in shows `time.sleep`, which only appears after the process has exec'd. The `claude()` helper and the stop test both call it. The headless-return test now uses `wait=4` and a 3 s bound.

**Production.** The race is not real there. `is_relay` and `headless` read long-lived processes (a pid-file listener, the Claude Code process running the hook), never a child spawned a moment earlier. No production code changed.
