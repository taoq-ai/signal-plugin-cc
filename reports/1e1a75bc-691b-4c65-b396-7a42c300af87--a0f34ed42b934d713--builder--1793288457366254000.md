**What changed** (7 files, 98 lines added, 3 removed):
- **Headless runs:** `listen` now returns at once in a `claude -p` run, before it sends anything or records a listener. The new `processes.headless()` reads the arguments of the Claude process named by `CLAUDE_PID` with `ps`. Headless means `-p` or `--print` without `--input-format stream-json`, so a Desktop session keeps its listener. The entrypoint variable alone is not trusted, as the probe advised. It only decides (`sdk-cli`) when the process can't be read.
- **Windows:** `relay.py` checks for `fcntl` before importing the package and exits 0 with no output without it. The check has to sit there because `cli.py` already pulls in `files.py`, which imports `fcntl`.
