**What changed:**
- **`entry/hooks.py`:** `quiet()` now does nothing for a prompt that opens with `<task-notification>` or carries the Signal wake text. The listener keeps running and away stays on. A typed prompt still sends SIGUSR1 and turns away off, even one that mentions `<task-notification>` mid-text. SessionEnd still sends SIGUSR2. A typed prompt or SessionEnd also clears the session's saved messages.
- **`adapters/files.py`:** `FileRegistry` saves each finished turn's message as a line in `threads/<session>`, written under `private.py`'s file rules (0600). `claim()` never gives out a saved tag, and it drops thread files with no new message for a day.
- **`app/conversation.py`:** the listener after a finished turn loads the session's earlier messages into its routing, then saves its own message. If saving fails, the listener still takes replies to its own message.
- **`domain/routing.py`:** a reply tagged with one of this session's earlier tags goes to its current listener. A reply tagged with another session's earlier tag is skipped, so it can never fall to a different session as a plain reply. A tag of a waiting prompt still wins.
