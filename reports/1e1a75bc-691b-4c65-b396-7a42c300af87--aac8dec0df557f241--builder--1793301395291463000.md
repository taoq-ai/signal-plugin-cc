**Fixes**
1. **Whitespace-only last message:** it now reads "Finished its turn.", as an empty one does. Tested with "  \n", a tab and U+2028.
2. **Who joins a digest:** only a session that waited in the presence loop (it finished while the owner was at the Mac) leads or joins one. A session that finds the owner already away sends its own message at once and is recorded as sent, so a later digest points at it. The Signal conversation path no longer waits 10 seconds.
   - The new `Leaving` presence in `tests/support.py` encodes the mock's definition of "finished while at the Mac".
   - `test_sessions_finishing_after_the_digest_send_their_own_message_at_once` runs with the gather window at 30 seconds, so a session that waited for it would fail the test.
3. **Poll pick of a taken-over session:** it now gets "[tag] That session no longer listens here; answer at the Mac."
   - A taken-over session's tag now gets that answer only once: prompts outside the digest skip the tag instead of also sending the hint.
   - Negative vote indexes and two picks name no session.
4. **Poll stays open:** the test now checks the poll is still open after the first member wakes, and closed once all have ended.
5. **Refused or lost poll:** the test now waits for both sessions to wake, so the lead must still be listening; it no longer depends on a timing window. An `OSError` on the poll send is caught like a refusal, so the lead keeps listening and no second digest goes out.
6. **Leftover entries:** clearing out entries of ended sessions is now tested. Each entry also records its listener's pid, so an entry left by a listener killed with SIGKILL is dropped when read.

Also done:
- **Docs:** the Gathering entry fields and digest shape are documented in `signal_cc/ports.py`, and Gathering is in the README architecture table.
- **Merge:** the merge of main (#11) conflicted only on import lines. `leave()` now deletes through #11's `private.remove`.
- **Tests:** the digest tests no longer assume the threads claim tags in order, which had made two of them flaky.
