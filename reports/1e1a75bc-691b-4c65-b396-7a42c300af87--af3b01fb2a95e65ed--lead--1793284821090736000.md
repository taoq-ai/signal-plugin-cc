## Riskiest item and the cheapest way to learn

The riskiest part is the Signal conversation itself, the Stop hook with asyncRewake. The installed Claude Code 2.1.311 binary shows two things:
- **Possible cap:** the Stop-hook block limit is `CLAUDE_CODE_STOP_HOOK_BLOCK_CAP ?? 8`. An asyncRewake exit 2 is delivered as a new queued message, so the cap probably resets on each wake, but that is unverified.
- **Headless runs:** asyncRewake runs in the background only when the session is interactive or has streaming input. So `claude -p` probably runs the `listen` hook synchronously. Each headless run would then wait up to 300 s at the Mac, or message Signal and wait up to 3600 s when the Mac is idle.

The cheapest check is rewake-probe: about an hour with throwaway hooks in a scratch folder, recorded with `wuwei plan run`. Plan-approval and leave-digest each start with their own small check: a throwaway hook for plan approval, and a text mock of the digest for the owner.
