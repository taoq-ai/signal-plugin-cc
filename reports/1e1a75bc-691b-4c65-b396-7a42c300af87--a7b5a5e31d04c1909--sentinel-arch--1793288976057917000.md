The arch gate verdict is **FIX** for relay-log at head a2726486. One finding blocks the merge.

**Blocking finding:** a continue prompt that the owner ends by typing at the Mac is logged as `error`, not `back at the Mac` (signal_cc/app/conversation.py:50).
- When the owner types at the Mac, the `quiet` hook stops the listener with SIGTERM.
- `exit_on_sigterm` (hooks.py:55) turns that into SystemExit while the prompt is still waiting.
- The `finally` in `ask` then writes the outcome that line 50 set earlier: `"error"`.
- A new turn's Stop hook and SessionEnd end the listener the same way.

So the normal way a continue prompt ends is counted as a relay error, which inflates G-2's error count. It breaks acceptance 2. A probe that sends SIGTERM to a running `continue_session` reproduced it: `{'kind': 'continue', ..., 'outcome': 'error', 'waited': 1.0}`.
