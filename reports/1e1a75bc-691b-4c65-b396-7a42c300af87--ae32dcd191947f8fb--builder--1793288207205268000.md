**How it works**
- **Commands:** `domain/routing.COMMANDS` now holds `status`, `away` and `back`. A prompt still takes a quoted `away` as its answer.
- **Presence port:** it gains `set_switch(on)` and `switch_on()`. `MacPresence(idle, switch)` checks the switch before idle time: when it is on, `away()` is true and `returned()` is false.
- **Idle time unknown:** this now counts as at the computer, as the item asks. Before, every prompt went to Signal.
- **Storage:** `adapters/files.AwaySwitch` stores the switch as the file `<home>/away`, which every session and the desk share. `wiring.presence(cfg)` builds it, so `wiring.py` is still the only place that builds adapters.
- **Desk:** `desk.serve(messenger, registry, presence)` flips the switch and confirms it. `status` now ends with the switch's state, and `texts.status` takes a new `away` argument.
- **`quiet()` in `entry/hooks.py`:** it turns the switch off only when `hook_event_name == "UserPromptSubmit"`. This is a three-line hunk at the top of the function, kept small for mac-answer-notice.
